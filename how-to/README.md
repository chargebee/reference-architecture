# How-Tos

If you're a developer or architect looking for the recommended way of integrating Chargebee with your app/platform, look no further! The topics below cover the best practices to achieve the required outcome and are vetted and updated continuously.

To make things easier, each of these topics are actually implemented in code. The [pointer](../pointer/README.md) app is our demo application built with an opinionated tech stack with all the required pieces to spin up a working SaaS platform. 

Regardless of what your tech stack or hosting platform, each how-to covers the functional/non-functional requirements and a production go-live checklist to help you along the journey.
